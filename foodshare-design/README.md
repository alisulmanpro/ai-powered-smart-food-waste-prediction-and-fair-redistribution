# FoodShare Admin Panel – Design Reference

Static design reference for the FoodShare admin panel (AI-Powered Smart Food Waste Prediction and Fair Redistribution).
These are visual references only: all numbers and names are **sample data**, and there is no backend logic.

## Contents
- `pages/` – 13 standalone HTML pages. Open `pages/01-sign-in.html` in a browser; buttons and the sidebar link between pages.
- `screenshots/` – a full-page PNG of every page (1360 px wide).
- `logo/` – logo and app icon (SVG and PNG, light and dark versions).

## Pages
01 Sign in · 02 Dashboard · 03 Verify users · 04 User details · 05 Allocations · 06 Review allocation · 07 Override allocation · 08 Collections · 09 Data & models · 10 Upload CSV · 11 Model details · 12 Settings · 13 Audit log
